# RuStore MVP — Android

Учебный MVP магазина приложений **RuStore**: онбординг → витрина с поиском и категориями → детальная карточка с установкой/удалением и полноэкранными скриншотами → профиль.

## Сборка и запуск

### Из Android Studio

1. Откройте корень репозитория **`vk_app`** в Android Studio.
2. Дождитесь окончания **Gradle Sync** (первый раз — несколько минут, тянет Compose BOM и Navigation).
3. Выберите конфигурацию **`app`** и эмулятор/устройство.
4. Кнопка **Run ▶** (или `Shift+F10`).

### Из командной строки (Windows / PowerShell)

```bat
gradlew.bat :app:assembleDebug
gradlew.bat :app:installDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Сброс онбординга

Способ 1 (внутри приложения): иконка профиля в правом верхнем углу витрины → кнопка **«Сбросить онбординг»**.

Способ 2 (через Android): Настройки → Приложения → RuStore → Хранилище → Очистить данные.

## Что реализовано

- Онбординг при первом запуске (логотип, приветствие, кнопка на витрину); повторные запуски сразу открывают витрину
- Сохранение флага «онбординг пройден» в DataStore
- Витрина со списком приложений: иконка, название, разработчик, рейтинг, категория, возрастной рейтинг, краткое описание
- Переход в карточку приложения по тапу
- Фильтр по категориям через bottom sheet («Категории») с счётчиками приложений
- Поиск по названию и разработчику на витрине
- Карточка приложения: кнопка «Назад», полное описание, рейтинг, скачивания, возраст, размер, версия, дата обновления
- Горизонтальная лента скриншотов с подписями («Главный экран», «Каталог» и т.д.)
- Полноэкранный просмотр скриншотов со свайпом, подписью и счётчиком страниц
- Имитация установки приложения с прогресс-баром и экраном «Открылось новое приложение»
- Кнопки «Открыть» и «Удалить» после установки
- Экран профиля (гость, версия приложения, сброс онбординга для тестирования)
- Процедурные иконки приложений (буква + цвет категории) без отдельных картинок
- Локальный каталог из 10 приложений (`FakeAppRepository`), без сетевого API
- Вертикальный скроллбар в длинной карточке приложения

## Маршруты навигации

| Route | Экран |
| --- | --- |
| `onboarding` | Онбординг |
| `store` | Витрина |
| `app_details/{appId}` | Карточка приложения |
| `profile` | Профиль |
| `screenshots/{appId}?startIndex={index}` | Полноэкранные скриншоты |
| `installed/{appId}` | Экран после установки (заглушка) |

Стартовая дестинация определяется в `MainViewModel` по флагу онбординга.

## Сценарии для проверки

1. **Первый запуск:** онбординг → «Перейти к витрине» → витрина. Повторный запуск — сразу витрина.
2. **Поиск:** ввод в поле «Поиск приложений» фильтрует список; крестик сбрасывает.
3. **Категории:** чип «Категории» → bottom sheet → фильтр списка.
4. **Карточка:** тап по приложению → детали, скриншоты, кнопка «Назад».
5. **Полноэкранные скриншоты:** тап по скриншоту → листание, подпись, «×» для выхода.
6. **Установка:** «Установить» → прогресс → экран «Открылось приложение» → «Назад» → в карточке «Открыть» и «Удалить».
7. **Удаление:** «Удалить» → снова «Установить».
8. **Профиль:** иконка на витрине → профиль → сброс онбординга.
